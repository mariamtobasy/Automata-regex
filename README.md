

### Automata Regex Project – Java & PHP
<br>
This project detects IP addresses (both IPv4 and IPv6) and shows IPv4 geographical location.  
It identifies where an IP belongs — for example, China, the United States, or other regions.
<br><br>
* Implemented a lexical analyzer in **Java** to validate IPv4/IPv6 addresses using regex, convert IPs to integers, and match them to country ranges.
*  **convert the Java logic to PHP** and create a web-based interface for IP input and country lookup.
* Applied pattern matching, data manipulation, and teamwork to deliver both a console and web-based solution.
* Course project completed in 2nd year.
